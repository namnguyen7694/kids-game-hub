# 🧩 Kids Learn Hub

Welcome to **Kids Learn Hub**, a vibrant educational platform featuring brain-training games for children. Built with Next.js 16 and React 19.

## 📚 Documentation
- [Product Specification](docs/product_spec.md) - Detailed vision, features, and tech stack.
- [Project Roadmap](docs/roadmap.md) - Development phases and future plans.

## 🎮 Current Games
- **Memory Match (Tìm Cặp Hình):** A classic memory game with multiple difficulties and multi-player support.
- *More coming soon!*

## 🛠️ Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the hub!

## 🚀 Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** CSS Modules
