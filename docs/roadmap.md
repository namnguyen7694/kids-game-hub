# Project Roadmap: Kids Learn Hub

*Status: In Progress*

- [x] Set up Next.js 16 + React 19 project structure.
- [x] Implement "Memory Match" core gameplay.
- [x] Add difficulty levels (Easy to Super).
- [x] Add multi-player support (1-4 players).
- [x] Basic responsive design for the Hub dashboard.
- [ ] **Polish:** Add sound effects for matches and turn transitions.
- [ ] **Polish:** Add "Confetti" celebration on game win.

## Phase 2: Logic & Persistence (Q2 2026)
*Goal: Expand game variety and user engagement.*

- [x] **Word Matching Card:** Implement flashcards for vocabulary learning (Emoji, EN, VI).
- [ ] **Logic Puzzles:** Implement a new game involving sequence matching or pattern recognition.
- [ ] **Local Persistence:** Save player high scores and "favorite" game settings in `localStorage`.
- [ ] **Theme Support:** Allow users to choose different card themes for Memory Match (Animals, Vehicles, Foods, etc.).
- [ ] **Player Profiles:** Allow players to choose an avatar and save their nickname.

## Phase 3: Math & Motivation (Q3 2026)
*Goal: Educational expansion and rewards.*

- [ ] **Math Adventure:** Implement a fast-paced arithmetic game with levels of increasing difficulty.
- [ ] **Achievement System:** Badges for "Memory Master", "Math Whiz", etc.
- [ ] **Daily Challenges:** A "Game of the Day" with bonus points.
- [ ] **Parental Dashboard:** Simple stats on which games the child plays most.

## Phase 4: Social & Multi-platform (Q4 2026+)
*Goal: Scalability and reach.*

- [ ] **PWA Support:** Make the hub installable on mobile devices.
- [ ] **Multi-language:** Add English support alongside Vietnamese.
- [ ] **Cloud Sync:** Optional login to sync progress across devices.
- [ ] **New Games:** Word Search, Simple Coding Blocks, and Drawing Canvas.
