# Product Specification: Kids Learn Hub

## Project Overview
**Kids Learn Hub** is a web-based educational platform designed to provide children with engaging, brain-training games. The platform focuses on cognitive development through play, offering a variety of challenges including memory, logic, and mathematics.

## Vision
To become the favorite digital playground for kids where they can learn, think, and grow through fun and interactive experiences.

## Target Audience
- **Children (Ages 4-10):** Primary users seeking fun and colorful games.
- **Parents/Educators:** Users looking for safe, educational content for their children.

## Core Features

### 1. Game Dashboard (The Hub)
- A vibrant, easy-to-navigate landing page.
- Visual game cards with clear icons and descriptions.
- Responsive design for tablets and desktop.

### 2. Memory Match (Tìm Cặp Hình)
- **Game Logic:** Find pairs of matching emojis within a grid.
- **Difficulty Levels:**
  - Easy (4x4)
  - Medium (6x6)
  - Hard (8x8)
  - Super (10x10)
- **Multi-player Support:** 1 to 4 players can compete in turns.
- **Turn Timer:** 10-second limit per turn to keep the game dynamic.
- **Celebrations:** Visual feedback ("TUYỆT VỜI!") when a match is found.

### 3. Word Matching Card (Thẻ Từ Vựng)
- **Concept:** Flashcards for vocabulary learning.
- **Content:** Emoji on the front, English and Vietnamese text on the back.
- **Categories:** Animals, Fruits, Vehicles, Weather, Sports, and Objects.
- **Interactivity:** 3D flip animation on click.

### 4. Planned Games (Coming Soon)
- **Logic Puzzles:** Challenges that require reasoning and deduction.
- **Math Adventure:** Fast-paced arithmetic games (addition, subtraction, etc.).

## Technical Stack
- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** CSS Modules (Vanilla CSS)

## Design Principles
- **Vibrant & Playful:** Use bright colors and friendly typography.
- **Kid-Friendly UX:** Large buttons, intuitive navigation, and minimal text.
- **Feedback-Rich:** Use animations and micro-interactions to reward progress.

## Success Metrics
- Average time spent per session.
- Number of games completed.
- Returning user rate (measured via local persistence).
